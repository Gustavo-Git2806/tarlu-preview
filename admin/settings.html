About

Tarlu Admin is a static content editor for the Tarlu preview site. Edits are persisted to your browser's localStorage and applied to the public pages via a lightweight override loader.

This is a preview-build admin — authentication is client-side and credentials are stored locally. Do not use this to protect real secrets. To publish edits, export the JSON and commit the resulting content file to the site repository.
